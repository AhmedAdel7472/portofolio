# Rodain Hisham Mohamed - Data Analyst Portfolio

A modern, responsive personal portfolio showcasing data analytics projects, skills, education, and professional experience.

## 🚀 Features

- **Dark / Light Theme Toggle**: Seamless mode switching with persistent user preference in `localStorage`.
- **Responsive Navigation**: Hamburger menu for mobile devices and sticky glassmorphic navbar with active scroll spy.
- **Dynamic Animations**: Smooth scroll and reveal-on-scroll animations using `IntersectionObserver`.
- **Project Showcase**: Detailed cards highlighting data analysis, visualization, and business intelligence projects.
- **Contact Form**: Interactive form with modern styling.

## 🛠️ Built With

- **HTML5** (Semantic structure, SEO optimized)
- **CSS3** (Custom properties, Flexbox/Grid, Glassmorphism, animations)
- **JavaScript** (Vanilla ES6+)
- **Font Awesome 6** (Icons)
- **Google Fonts** (Inter & Poppins)

## 🌐 Deploy to Vercel

This repository is pre-configured and ready to deploy directly on [Vercel](https://vercel.com):

1. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
2. Import this GitHub repository (`AhmedAdel7472/portofolio`).
3. Leave all build settings as default (Framework Preset: **Other** or automatically detected as static).
4. Click **Deploy**.
